# 🍽️ Zomato Restaurant Data Analysis

## 📌 Project Overview

This project analyzes Zomato restaurant data to understand restaurant distribution, customer preferences, pricing patterns, and service availability across different cities and countries.

The objective is to derive meaningful insights that help businesses improve customer experience and optimize service offerings.

---

## 🎯 Business Objective

The goal of this project is to:

* Analyze restaurant distribution across cities and countries
* Understand trends in restaurant openings over time
* Evaluate customer preferences based on ratings and cuisines
* Study pricing patterns and cost distribution
* Analyze service features like online delivery and table booking

---

## 📂 Dataset Description

The dataset contains information about restaurants including:

* Restaurant location (City, Country)
* Opening date
* Average cost for two
* Ratings
* Cuisines
* Online delivery and table booking availability

---

## 🛠 Tools & Technologies

* Power BI → Data Visualization & Dashboard
* Excel/CSV → Data Source
* Data Modeling → Relationship building & transformations

---

## 🔧 Data Preparation & Modeling

* Built a data model using multiple sheets

* Created a **Calendar Table** using opening date

* Derived additional fields:

  * Year, Month, Quarter
  * Year-Month format
  * Weekday information
  * Financial Month & Financial Quarter

* Converted average cost into **USD** for standardization

---

## 📊 Key Analysis Performed

* Number of restaurants by **City and Country**
* Restaurant openings trend by **Year, Quarter, and Month**
* Distribution of restaurants based on **Ratings**
* Price segmentation using **cost buckets**
* Percentage analysis of:

  * Restaurants offering **Table Booking**
  * Restaurants offering **Online Delivery**
* Cuisine-based and location-based performance analysis

---

---

## 📈 Key Insights

* Certain cities have significantly higher restaurant concentration
* Restaurant growth shows clear trends over time (monthly & yearly)
* Higher price does not always guarantee higher ratings
* Only a limited percentage of restaurants offer table booking
* Online delivery availability varies significantly across locations
* Some cuisines dominate specific regions

---

## 💡 Business Recommendations

* Expand services (online delivery & table booking) in high-demand areas
* Focus on mid-range pricing strategies for better customer reach
* Invest in high-performing cuisines based on region
* Use time-based trends to plan new restaurant launches
* Improve customer experience to boost ratings
